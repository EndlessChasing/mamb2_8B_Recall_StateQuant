both contexts are active. Use `reset=True` for a new request. The adapter has
no EMA or extra recurrent state. Leaving the contexts releases request caches
and removes adapter hooks. This API does not support native `InferenceParams`
or variable-length batching.

Memory scope is **batch one**, including one shared static 57,344-byte table:
28,499,968 bytes for packed SSM/convolution/table plus 2,308,208 resident FP16
adapter bytes = 30,808,176 bytes. The original source weights remain FP16,
16,473,999,360 bytes, and are not included in that sum. Temporary computation,
allocator reserve and training teacher/optimizer/checkpoints are also excluded.
The exported adapter file has serialization overhead; its actual file size is
reported separately. This is not a total-model-memory compression claim.
